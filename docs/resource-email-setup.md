# 이메일 확인 후 자료 다운로드
현재 상태: 코드 구현, 발신 도메인 인증과 환경변수 설정 후 활성화.
일반 방문자에게 발송할 수 없는 onboarding@resend.dev 테스트 발신 주소는 허용하지 않는다.

## 활성화
1. Resend → Domains → Add domain에서 humanai-edu.kr 또는 별도 발송용 하위 도메인을 등록한다.
2. Resend 화면에 나오는 DKIM/SPF 등의 DNS 레코드를 도메인 DNS 관리 화면에 정확히 등록하고 Verified 상태를 확인한다. 기존 수신용 MX는 임의로 교체하지 않는다.
3. Vercel의 실제 운영 프로젝트 hai-homepage에 환경변수를 설정한다.
   - RESEND_API_KEY: 기존 발송 키 (인증한 도메인의 Sending 권한 필요)
   - RESOURCE_FROM_EMAIL: 휴먼AI융합교육원 <자료발신주소@인증한도메인>
   - RESOURCE_TOKEN_SECRET: 암호학적 난수 32바이트 이상. 예: node -e "console.log(require('node:crypto').randomBytes(32).toString('base64url'))"
   - RESOURCE_BASE_URL: https://www.humanai-edu.kr (기본값과 같아 생략 가능)
   - CONTACT_TO_EMAIL: 확인 완료 알림 수신 주소. 기본 orthia66@gmail.com.
4. Vercel WAF에서 /api/resource-request에 공유 IP 기준 속도 제한(예: 15분 15회)을 설정한다. 코드의 제한은 서버 인스턴스별이므로 여러 인스턴스 전체를 보장하지 않는다. 브라우저별 서명된 60초 쿨다운도 적용한다.
5. 미리보기 환경에도 해당 발송 설정을 연결하고 RESOURCE_BASE_URL을 해당 미리보기의 HTTPS 주소로 설정해 확인 링크가 같은 배포를 가리키게 한다.
6. 수신할 수 있는 주소로 실제 발송→메일 클릭→확인 버튼→PDF 다운로드를 확인한 뒤 운영 배포한다. 테스트 시 이메일 소유자의 허가를 받는다.

## 동작
- 홈페이지 제출 시 신청자에게만 확인 메일을 보낸다. 교육원에는 아직 미확인 신청을 보내지 않는다.
- 확인 페이지에서 명시적으로 버튼을 눌러야 확인 완료로 처리한다. 메일 보안 검사기의 단순 GET은 확인 처리하지 않는다.
- 확인 완료 시 교육원에 이름·기관·자료·동의 내역을 '이메일 확인 완료' 제목으로 알린다.
- 링크는 AES-256-GCM 암호화, 30분 만료. URL fragment로 전달해 서버 접근 로그·referrer에 토큰을 남기지 않는다.
- 토큰은 30분 동안 재시도 가능한 확인 링크다. 단일 사용을 보장하지 않는다. 서버 저장소 없이 Resend 24시간 idempotency로 확인 알림 중복을 억제한다.
- HttpOnly/SameSite 쿠키로 신청 자료 1종에만 15분 접근을 허용한다. 세션스토리지의 기존 hai_dl_ok 값은 더 이상 사용하지 않는다.
- PDF 3종을 public 밖 resources 폴더로 이동하고 서버가 권한 확인 후 제공한다. 예전 정적 URL은 신청 화면으로 이동한다.
- 이 저장소는 공개 저장소이므로 파일 자체의 비밀성/재배포 방지가 목적은 아니다. 기존 공개 사본·다운로드를 회수하지는 않는다.
- 확인은 메일함 접근 권한만 증명하며 실명·기관 소속은 증명하지 않는다. 개인 이메일도 허용한다.
- 선택적 제안서/마케팅 수신 동의를 필수 확인 메일과 분리해 유지한다.

## 확인 항목
자동 테스트: npm run test:resources
타입/빌드/린트: npx tsc --noEmit, npm run build, npm run lint
실메일 송수신과 Vercel WAF는 별도 운영 검증이 필요하다.

## 이번 수정본의 검증 결과
- 자동 테스트 8개 통과: 미확인 차단, 정상 확인 후 다운로드, 만료·변조·목적이 다른 토큰 거부, 입력·동의 검증, 발송 실패, 재발송 제한 등. 테스트 메일은 외부 발송하지 않음.
- TypeScript, ESLint, Next.js 16.3.5 운영 빌드 통과.
- PC 1366×900 / 모바일 390×844 화면에서 신청 완료, 주소 수정, 확인 완료 후 버튼 표시를 검증. 페이지 오류 0건. UI 메일 응답은 테스트 대역을 사용.
- 실제 운영 빌드 HTTP 응답: 미인증 다운로드 401, 이전 PDF 경로 307, 발신 설정 미완료 503.
- 함수 배포 추적 파일에 보호 PDF 3종 포함.
- Resend 도메인 인증, 발신 주소·토큰 비밀키 환경변수, 공유 WAF 제한, 실제 메일 수신은 운영 활성화 전 확인 필요.
