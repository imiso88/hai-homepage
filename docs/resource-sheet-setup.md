# 확인 완료 자료 신청 자동 저장

대상: 기존 비공개 Google Sheets ‘휴먼AI융합교육원 교육 문의 관리’의
‘자료 신청·이메일 확인 완료’ 탭. 기존 문의 탭은 변경하지 않는다.

## 최초 연결

1. 별도의 Apps Script 프로젝트를 만든다. 기존 프로젝트의 코드를 덮어쓰지 않는다.
2. `scripts/resource-sheet.gs` 코드를 넣는다.
3. 프로젝트 설정 → 스크립트 속성에 `RESOURCE_SHEET_SECRET`을 설정한다.
   암호학적 난수 32바이트 이상을 사용한다. 이 값은 GitHub나 채팅에 게시하지 않는다.
   설치용 로컬 파일에는 같은 비밀값이 미리 들어 있어 속성을 따로 입력하지 않아도 된다.
4. 배포 → 새 배포 → 웹 앱. 실행 사용자: 나, 액세스 권한: 모든 사용자.
   소유자가 Google 권한 승인을 직접 완료한다. 시트 자체의 공유 설정은 비공개로 유지한다.
   웹 앱은 서명 검증을 통과한 POST만 저장하고, GET이나 조회 기능은 제공하지 않는다.
5. 웹 앱 `/exec` URL을 실제 Vercel 프로젝트 `hai-homepage`의 운영 환경에
   `RESOURCE_SHEET_WEBHOOK_URL`로 설정한다.
6. 동일한 비밀값을 `RESOURCE_SHEET_SECRET`으로 서버 전용 Secret 환경변수에 설정한다.
   기존 교육 문의용 `SHEET_WEBHOOK_URL`과 분리해 기존 동작을 보존한다.
7. 재배포 후 실제 이메일 확인 → 시트 1행 생성 → 같은 링크 재시도 시 행 수 불변을 확인한다.

## 동작과 오류 처리

- 확인 전에는 시트에 저장하지 않는다. 확인 링크의 명시적 POST 이후에만 저장한다.
- 신청 ID와 신청 시각은 원래 암호화된 신청 토큰의 값을 사용한다.
- HMAC-SHA256 서명과 5분 유효 시각을 검사한다. URL과 비밀값은 브라우저로 보내지 않는다.
- Apps Script의 ScriptLock 안에서 ID 중복 검사와 행 추가를 수행한다.
  저장 후 응답이 유실되어도 같은 ID의 재시도는 기존 행을 유지한다.
- 사용자 입력은 수식으로 실행되지 않도록 이스케이프하고 텍스트로 기록한다.
- 선택 수신 동의와 제안서 요청 여부를 구분해 저장한다. 마케팅 미동의는 광고 발송 대상에서 제외한다.
- 두 환경변수가 모두 없으면 기존 메일 방식이다. 일부만 있거나 저장이 실패하면 성공을 표시하지 않고 재시도를 안내한다.
- 시트 저장과 교육원 알림 메일은 함께 시도한다. 시트 저장 성공 시 알림 메일 장애가 다운로드를 막지 않는다.
- 이메일 확인 시각은 최초 저장 시각이다. 다운로드 파일 전송 성공이나 열람 사실을 의미하지 않는다.
- 동일인이 다른 자료를 다시 신청하면 새 신청 ID로 별도 기록된다.

## 운영

- 시트를 공개 링크로 공유하지 말고 필요한 담당자만 접근한다.
- 보유 기간 1년이 지난 기록과 삭제 요청을 받은 기록은 담당자가 삭제한다.
  자동 파기 트리거는 이 변경에 포함하지 않는다. 이메일 사본도 별도 관리한다.
- Google 장애/할당량 초과 시 확인 페이지의 재시도와 교육원 알림 메일을 확인한다.
  Apps Script 실행 로그와 Vercel 로그에 개인정보/서명/비밀값을 출력하지 않는다.
- 이 기능 활성화 이후 확인한 신청부터 저장한다. 과거 이메일의 일괄 이전은 포함하지 않는다.

자동 검증: `npm run test:resources` — 메일/API 테스트와 Apps Script 로컬 대역 테스트.
실제 Google 배포·권한 승인 후 운영 저장 검증은 별도로 필요하다.
